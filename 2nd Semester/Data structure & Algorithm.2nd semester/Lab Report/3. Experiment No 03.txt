2. Experiment Name:
Array Operations in C (Insert, Delete, Search, Traverse)


3. Introduction:
In this experiment, we learn how to work with arrays in C programming.
An array is a collection of elements stored at contiguous memory locations.
We can perform different operations like inserting new values, deleting values, searching for an element, and displaying all elements.

4. Codes/Figure: (Example in C)


#include <stdio.h>

int main() {
    int arr[10] = {10, 20, 30, 40, 50};
    int n = 5; // Current size
    int i;

    printf("Array elements:\n");
    for (i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }

    // Insert new element
    arr[n] = 60;
    n++;

    printf("\nAfter insertion:\n");
    for (i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }

    return 0;
}


5. Explanation:

Line 1-2: Include the standard I/O library.

arr[10]: An integer array with a maximum size of 10.

n = 5: Initial number of elements.

First loop: Prints all elements in the array.

Insertion: Add a new element at the end, increase n.

Second loop: Displays updated array.
